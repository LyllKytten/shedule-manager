# Telegram-бот "Расписание"

Бот на `pyTelegramBotAPI` (telebot) + `sqlite3` для управления личным расписанием.

## Возможности

- **Вход по паролю.** Первое, что видит новый пользователь — запрос пароля.
  Сообщение с паролем бот сразу удаляет из чата (после проверки), так что
  пароль не остаётся в истории переписки. Пароль задаётся один на весь бот
  через `ACCESS_PASSWORD`.
- `/add` — пошагово добавить событие: название → дата → время начала →
  длительность → нужно ли закладывать время на дорогу домой после него →
  повторение (не повторять / каждый день / каждую неделю / через N дней) →
  количество повторов.
- `/schedule [дата]` — расписание на дату (по умолчанию сегодня); события с
  дорогой домой после отмечены 🚗.
- `/week [дата]` — все события за 7 дней вперёд (по умолчанию начиная с
  сегодня), сгруппированные по датам.
- `/free [дата]` — свободные интервалы на дату, с учётом дороги домой только
  там, где она реально нужна.
- `/edit` — изменить любое поле события, включая флаг «дорога домой после».
- `/delete` — удалить событие; если оно часть повторяющейся серии, бот
  спросит — удалить только это вхождение или всю серию.
- `/settings`, `/travel_time <мин>`, `/working_hours <ЧЧ:ММ> <ЧЧ:ММ>` —
  настройки времени на дорогу и границ дня.
- `/cancel` — отменить текущий шаг/диалог.

Дату можно вводить как `сегодня`, `завтра`, `25.12` (текущий год) или `2026-12-25`.

## Как это работает

### Время на дорогу — теперь per-event
Раньше буфер на дорогу добавлялся после каждого события автоматически. Теперь
это отдельный флаг `needs_travel_time` у каждого события (спрашивается при
создании, меняется через `/edit`). При расчёте `/free` буфер `travel_time_minutes`
добавляется только после тех событий, где этот флаг включён — например,
после онлайн-созвона дорога не нужна, а после очного урока — нужна.

### Рабочие часы через полночь
Если `day_end` меньше `day_start` (например, `06:30`–`01:00`), бот понимает
это как рабочий день, уходящий за полночь, и правильно считает свободное
время до часа ночи следующих суток. Учтите: события, попадающие на раннее
утро следующего календарного дня (00:00–01:00), хранятся под датой этого
следующего дня — `/free` их не подхватит автоматически, их нужно смотреть
через `/free завтра` (или соответствующую дату).

### Повторение
При создании можно выбрать: не повторять, каждый день, каждую неделю или
задать произвольный шаг в днях, а затем — сколько раз повторить: 4, 8, 12,
своё число или **♾ бесконечно**. Бот создаёт отдельную строку в БД на каждое
вхождение и связывает их общим `series_id`.

Бесконечная серия физически не хранит бесконечно много строк: при создании
материализуются события на ближайшие ~90 дней, а дальше бот сам подгружает
следующие вхождения, как только вы запрашиваете `/schedule`, `/free` или
`/week` на дату, выходящую за пределы уже созданного — с запасом ещё на
~30 дней вперёд, чтобы не продлевать на каждый мелкий запрос. Если позже
вы удалите событие как «всю серию», подгрузка новых вхождений для неё
автоматически прекратится.

Редактирование меняет только одно конкретное вхождение; удаление позволяет
выбрать — удалить одно вхождение или всю серию целиком.

### Вход по паролю
Все команды, кроме `/cancel`, требуют авторизации (проверяется флаг
`is_authorized` в таблице `settings` по `user_id` из Telegram). Если
пользователь не авторизован, любая команда переводит его в диалог ввода
пароля. Введённое сообщение с паролем бот удаляет (`deleteMessage`) сразу
после проверки — в приватных чатах боты могут удалять входящие сообщения,
это штатная возможность Bot API. После успешного входа авторизация
сохраняется в БД навсегда (пока вручную не сбросить запись в `settings`).

Все события и настройки хранятся в SQLite (`schedule.db`, создаётся
автоматически рядом с `bot.py`). У каждого пользователя (по `user_id` из
Telegram) — свои события и свои настройки.

## Установка и запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram.
3. Задайте токен и пароль входа через переменные окружения (рекомендуется):
   ```bash
   export BOT_TOKEN="ваш_токен_сюда"
   export ACCESS_PASSWORD="ваш_пароль_сюда"
   ```
   Либо впишите значения напрямую в `config.py`.
4. Запустите бота:
   ```bash
   python bot.py
   ```

## Структура проекта

```
schedule_bot/
├── bot.py           # обработчики команд, диалоги добавления/редактирования, логин
├── database.py       # работа с SQLite (события, повторы, настройки, авторизация)
├── utils.py           # парсинг дат/времени, расчёт свободных интервалов
├── config.py          # токен бота и пароль входа
├── requirements.txt
└── README.md
```

## Возможные доработки

- Напоминания за N минут до события (через планировщик, например `APScheduler`)
- Часовой пояс пользователя
- Разные "рабочие часы" на разные дни недели
- Ограничение количества попыток ввода пароля (защита от подбора)
